## 🧠 What I'm building — The Edge Agent (TEA)

Open-source (MIT) **neurosymbolic AI agent-orchestration** framework. YAML-first, an alternative to
LangGraph/AutoGen — that **proves** its conclusions and runs **offline on the edge**.

- ⏱️ **Anticipated the market:** shipped graph-orchestrated **parallel (fan-out/fan-in) agent
  workflows in Sep 2024** — ~20 months before Claude Code's *Dynamic Workflows* (May 2026).
  *Verifiable in the git history.*
- 🔗 **Neurosymbolic reasoning:** LLMs + **Prolog (SWI-Prolog)** + a **KuzuDB** knowledge graph,
  so small/local models reason without hallucinating.
- 📦 **Edge / offline by design:** single binary, **Rust** & **WASM** builds, local **GGUF** LLM
  inference (llama.cpp, **Vulkan** GPU).
- 🐍 **Advanced Python:** 20+ built-in actions (LLM, RAG/pgvector, memory, web, distributed tracing);
  property-based testing (Hypothesis); ruff/pre-commit; multi-platform CI (AppImage, Docker, npm).
- ✍️ **28 technical articles** on neurosymbolic AI, workflow orchestration, and edge inference.
